Símbolos
Ver solución esperada

3 · BD

✍️ Ejercicio 3.1: crear las tablas Medio

Escribí el SQL para crear clientes, productos y compras. Incluí PRIMARY KEY, FOREIGN KEY y los tipos INT, VARCHAR, DECIMAL y DATE.

Símbolos
Ver solución esperada 
CREATE TABLE clientes (
  id_cliente INT PRIMARY KEY,
  nombre VARCHAR(50),
  apellido VARCHAR(50)
);

CREATE TABLE productos (
  id_producto INT PRIMARY KEY,
  nombre VARCHAR(50),
  precio DECIMAL(10,2)
);

CREATE TABLE compras (
  id_compra INT PRIMARY KEY,
  id_cliente INT,
  id_producto INT,
  fecha DATE,
  cantidad INT,
  FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente),
  FOREIGN KEY (id_producto) REFERENCES productos(id_producto)
);

✍️ Ejercicio 3.3: consultar con JOIN Difícil

Escribí un SELECT que muestre el nombre del cliente y el nombre del producto de cada compra. Usá FROM compras, dos JOIN y ON.

Símbolos
Ver solución esperada 
SELECT clientes.nombre, productos.nombre
FROM compras
JOIN clientes ON compras.id_cliente = clientes.id_cliente
JOIN productos ON compras.id_producto = productos.id_producto;
